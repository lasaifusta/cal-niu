# Cal Niu

Web del projecte rural **Cal Niu** — Castellar del Riu, Berguedà.

🌐 En producció: [calniu.com](https://calniu.com)

Lloc estàtic multipàgina (HTML · CSS · JavaScript, sense framework): presentació del projecte, història, activitats i un programa de voluntariat amb formulari d'inscripció i guia en PDF.

## Pàgines
- `index.html` — inici
- `projecte.html` · `historia.html` — el projecte i la seva història
- `activitats.html` — activitats
- `participa.html` · `voluntariat.html` · `voluntariat-inscripcio.html` — participació i voluntariat
